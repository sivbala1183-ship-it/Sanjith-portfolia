SANJITH KRISHNA — PERSONAL PORTFOLIO
Files:
- index.html: page structure and Bootstrap components
- style.css: custom dark theme and responsive styling

BEFORE PUBLISHING:
1. Replace sanjith@example.com with your real email address.
2. Add your own LinkedIn profile URL.
3. Check project descriptions and update them to match your actual work.
4. Open index.html in a browser and test the navigation and mobile layout.

DEPLOY WITH GITHUB PAGES:
1. Sign in to GitHub and create a public repository named sanjith-portfolio.
2. Upload index.html, style.css and README.txt to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for the Pages URL to appear. It will look like https://YOUR-USERNAME.github.io/sanjith-portfolio/
7. Open the live URL on desktop and phone. Fix anything that looks incorrect.

Note: Bootstrap and Google Fonts are loaded from online CDNs, so an internet connection is needed for those extras. The page itself is plain HTML and CSS.
